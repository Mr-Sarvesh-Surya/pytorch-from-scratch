# pytorch-from-scratch

This repository documents my learning and experiments with **PyTorch**, ranging from the basics of tensors and automatic differentiation to building and training deep learning models.  

The goal of this repo is to keep track of well-documented code snippets, implementations, and notes that can be helpful for both personal reference and for anyone starting with PyTorch.

---


---

## 🚀 Topics Covered
- PyTorch fundamentals (tensors, autograd, datasets, dataloaders)  
- Model building with `torch.nn`  
- Training and evaluation pipelines  
- Optimization algorithms (SGD, Adam, etc.)  
- Example models: MLP, CNN, etc.  
- Custom datasets and transforms
